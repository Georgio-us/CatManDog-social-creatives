# CatManDog Social Creatives

Локальная песочница и коллекция креативов CatManDog

Откройте `index.html` двойным щелчком. Сборка и интернет для просмотра не нужны. Кнопка «Коллекция креативов» открывает шесть готовых PNG размером 1080 × 1350. Каждый можно скачать отдельно или вместе в ZIP

Песочница позволяет переключать шрифт и формат, менять текст и изображения, а также экспортировать активный вариант. Настройки сохраняются в браузере

Исходные изображения, шрифты, логотип и готовые PNG лежат внутри этой папки. Для повторной сборки коллекции нужен Python и Pillow: `python3 build_collection.py`
